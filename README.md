## 1. 导入 ima

1. 下载 `china-supply-chain-origins.zip`（见 `_dist/`）
2. ima → 技能 → 导入 / 上传技能包 → 选这个 zip
3. 导入后技能名为 `china-supply-chain-origins`


## 3. 数据长什么样

```json
{
  "no": 79,
  "product_raw": "汉服",
  "places_raw": "保定容城县容城镇",
  "verdict": "fix",
  "verdict_cn": "需修正",
  "product": "汉服",
  "place": "山东菏泽曹县（大集镇）",
  "note": "曹县汉服占全国50%以上，2024年销售额119.7亿元；容城为服装加工（雄安）",
  "level": "A",
  "level_cn": "政府文件/国家级授牌"
}
```

判定：`ok` 属实 / `fix` 需修正 / `doubt` 存疑 / `dup` 重复
等级：`A` 政府文件或国家级授牌 / `B` 权威媒体或行业协会 / `C` 未逐条取证

## 5. 边界

| 不做 | 原因 |
|---|---|
| 编造或补全未核实的条目 | 14 条存疑就是存疑，不凑数 |
| 提供企业名录与联系方式 | 只到镇级 |
| 承诺最低价、独家货源 | 产业带 ≠ 便宜；同镇品牌厂与白牌厂报价能差 3 倍 |
| 覆盖第 101—200 条 | 原文说“下方还有100份”，该续篇未获取 |
| 替代实地验厂 | 核实的是产地，不是某家厂的交期与品控 |

份额数字来自各来源的发布时点，用于采购决策前建议重新核一次。
