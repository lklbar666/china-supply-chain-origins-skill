# 05 · 使用指南：拿这张表去做什么

这张表有三种用法，按你要解决的问题选。

---

## 用法 A · 按产品找产地

```
问：我想找 XX 的代工，去哪？
答：先查 02 号总表 / 或跑 scripts/lookup.py --product XX
```

```bash
python scripts/lookup.py --product 汉服
python scripts/lookup.py --product 牙刷
python scripts/lookup.py --verdict fix          # 只看 25 条修正项
python scripts/lookup.py --level A              # 只看有政府文件/授牌支撑的
python scripts/lookup.py --province 山东
```

输出的“核定地点”可以直接拿去 1688 / 地图 / 招商局搜。

**注意顺序**：先看判定。
- 标 ✅ 的可以直接用
- 标 ✏️ 的**用“应为”那一行**，别用原文
- 标 ⚠️ 的不要用

---

## 用法 B · 按地区找品类

如果条件反过来——你人在某地，或要在一个省内配齐多个品类：

→ 看 `04-区域分布：按省看这张表.md`

典型场景：
- 想做一站式采购，去**广东**（一个镇一个品类，配套半径 5 公里）
- 想找“单点冠军”做独家款，去**江苏/浙江**（一个镇占全球 1/3）
- 想找体量大、价格低、名气小的，去**山东/河北**（隐形冠军省）

## 用法 C · 验一条新说法

看到另一张清单、或某个博主说“XX 镇是 XX 之乡”：

→ 按 `01-方法论` 的四步走：拆 → 验行政区划 → 查授牌/政府文件 → 反查龙头

先用六类错误扫一遍（E1 行政区划 / E2 错字 / E3 张冠李戴 / E4 市场当产地 / E5 漏龙头 / E6 产品名）。
这份清单 25 条错的，20 条以上能被六类扫描直接命中。

**判断下限**：拿不到一级（政府文件）或二级（国家级授牌）证据，就写“存疑”，不要给结论。

## 用法 D · 找供应商的三层筛

查到产地**只是第一步**。从“这个镇做这个产品”到“这家厂能给你供货”，中间还有两层。

### 第一层：产地 → 园区

一个镇可能有 3—5 个园区，定位不同。
例：博兴县厨具 2800 家企业，90% 在兴福镇和曹王镇；
曹王镇有“中一厨具电商物流产业园”，兴福镇偏大型整体厨房。

**怎么查**：搜“〈镇名〉+ 产业园 / 工业园 / 集聚区”，或看镇政府官网的“园区建设”栏目。
博兴、清河、临湘这类产业强县的政府网站，都有“支柱产业”“重点企业”专栏。

### 第二层：园区 → 企业

**1688 上的“源头工厂”标签不等于它是工厂。** 平台标签是商家自填 + 平台规则判定，
判的是“有没有工厂资质”，不判“是不是这个产业带的”。

三件事能快速验：

| 查什么 | 怎么查 | 说明 |
|---|---|---|
| 注册地址 | 企查查/天眼查 | 地址是否落在那个镇/园区 |
| 经营范围 | 同上 | 有没有“生产/制造”，还是只有“销售” |
| 厂房与设备 | 要视频/实地 | 注塑机吨位、生产线数量、工人数 |

第 52 条“新乡古固寨兽药”就是这个坑：古固寨镇的企业绝大多数是**兽药经营部**（零售/批发），
生产企业在新乡县经开区七里营工业园。**“这里能买到”和“这里能造”是两件事。**

### 第三层：企业 → 你的订单

到这一步才谈价格、起订量、打样。产业带的价值在这里体现：

- **配套半径**：澄海一个区能配齐玩具全部零件；狮岭一个镇能配齐包的全部五金
- **小单快反**：曹县汉服能做到 72 小时小批量出货
- **成本**：曹县汉服成本比外地低约 50%；鄌郚吉他 5 公里内配齐所有配件

**如果对方说“我们在 XX 产业带”，但打样要 20 天、配件要外省调** —— 那它多半只是注册在那里。

## 用法 E · 别把这张表当成“最低价名单”

三个必须说清的限制：

1. **产业带 ≠ 便宜**。产业带的优势是配套和快反，不是绝对低价。
   同一个镇里，做品牌的厂和做白牌的厂，报价能差 3 倍。
2. **份额数据有时效**。表里的“占全国 X%”来自政府文件或媒体报道的**某个时点**，
   产业会转移（打火机从广东转到邵东，吉他从广州转到正安），数字要复核。
3. **“之乡/之都”是授牌，不是排名**。中国轻工业联合会等机构授出的称号有几百个，
   同一个品类可能好几个地方都有称号（例如“中国XX之乡”常有 2—3 个）。
   **授牌证明“这里有产业”，不证明“这里是唯一或最大”。** 要比份额，看谁在报数字。

## 一句话流程

```
产品 → 查表拿「核定地点」→ 看判定（✅用 / ✏️用修正值 / ⚠️弃）
     → 搜园区 → 验工商注册地址与经营范围 → 要厂房视频 → 打样
```

跳过任何一步，都可能落到“注册在产业带、实际在外省代发”的中间商手里。
